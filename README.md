# 지문까지

2026 제8회 KB Future Finance A.I. Challenge 출품작
**「지문까지」 — 메뉴를 대신 걷는 실행형 AI 에이전트**

> 안내하지 않습니다. 대신 합니다.

## 구조

- **L1 라우팅** — KB 3사 전체 메뉴 인덱스에서 "그건 여기 있습니다"
- **L2 조회** — 데이터를 조합해 바로 답변
- **L3 실행** — 부수효과 경고 후 본인 인증으로 실행

## 실행
